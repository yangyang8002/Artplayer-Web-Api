                    自研 Canvas 弹幕引擎 · API 限流与实时统计 · PoW 防火墙 · 双主题系统 · 多字幕 · 文件管理

功能一览

                

                    
· 自研 Canvas 弹幕引擎（轨道/堆叠/密度）

                    
· DPlayer 兼容弹幕 API

                    
· 服务端分配 8 位视频 ID（自动继承旧 ID）

                    
· 多字幕自动检测与切换（简/繁/日/英…）

                    
· API 独立开关 / RPS / 带宽控制

                    
· API 统计：1s 精度实时曲线，保留 1-90 天

                    
· PoW 工作量证明防火墙

                    
· 全局速率限制 / 弹幕频率限制

                    
· 播放器 + 后台双主题（各 10 套）

                    
· 屏蔽词 + GitHub 词库订阅

                    
· 文件管理：压缩/解压/批量操作/上传

                    
· 请求日志（最近 500 条）
